Read this once. This page is not a login-protected dashboard, because the site is hosted as static files on GitHub Pages and there is no server to check a password against. A password box here would only be for show. It holds no customer data and it is blocked from search engines. Treat the URL as unlisted, not as secret. Orders do not appear here: they arrive in your WhatsApp. What this page does is edit assets/js/config.js, the one file that every price, policy and contact detail on the website is read from.

What is still missing

Anything marked outstanding is hidden from customers right now. The site will not print a fact it cannot stand behind, so filling these in is what makes the page fill out.

    Preview mode

    While this is on, every page carries a red pre-launch bar listing what is unconfirmed. Turn it off only when the launch checklist in the repository is signed off.

    Before you advertise this anywhere

    These are not website settings. They are the things that decide whether running an advert is legal and whether the advert will survive review.

    • Required NAFDAC product registration for a herbal product sold commercially in Nigeria.
    • Required NAFDAC advertisement approval, which is separate from product registration.
    • Required ARCON / Advertising Standards Panel approval for the advert itself.
    • Check Meta restricts sexual-enhancement products and reviews the landing page, not just the advert.
    • Check TikTok prohibits advertising products intended to enhance sexual performance. Renaming the category does not change that.
    • Done No fake countdowns, stock counters, invented reviews or before-and-after claims anywhere on this site.

    Registered business

    The seller's legal name and address. Required before launch: a commercial site with no identified seller behind it is a problem both legally and for customer trust.

    Customer contact

    Orders are sent to the WhatsApp number below. If no number is confirmed here, the order button on the site switches itself off rather than pretending to work.

    Only tick "confirmed" against a document. A supplier saying it on the phone is not a document. The packaging artwork supplied with this build is AI-generated and its label text is garbled nonsense, so it is not evidence of anything either.

    Label facts

    Each of these appears in the product panel on the website only once it is confirmed.

    Packages and prices

    Prices in Naira, no commas. The site works out the price per bottle itself and tells the customer which pack is genuinely the best value, so the numbers here need to make sense.

    Delivery

    Confirm these with the courier you actually use, not with the old sales page.

    Payment

    Returns

    Write the conditions out. "100% money back" with unwritten conditions attached is how customers end up feeling cheated, and it is the single most common cause of a chargeback dispute.

    Page activity

    Counts held in this browser only. The site sends nothing to any analytics or advertising service, deliberately: transmitting page context for a product in this category to an ad platform is exactly the kind of sensitive-data leak you do not want. For real traffic numbers across all visitors you would need a privacy-respecting analytics host, which means leaving static hosting.

    Orders

    Orders are not stored on this website. There is no server and no database, so there is nothing here to list. Every order arrives as a WhatsApp message containing the reference, the package, the total and the delivery address. Keep your order book in WhatsApp, or in a spreadsheet you fill from it.
